# Credit Card Fraud Detection

## Project Overview
Credit Card Fraud Detection is a Machine Learning project that identifies potentially fraudulent credit card transactions. It uses data analysis and machine learning algorithms to distinguish between legitimate and fraudulent transactions.

## Objectives
- Analyse credit card transaction data.
- Perform data preprocessing and cleaning.
- Handle missing values and duplicate records.
- Detect and handle outliers.
- Encode categorical variables.
- Perform data visualization.
- Apply feature selection and standardization.
- Train and evaluate machine learning models.
- Identify fraudulent transactions accurately.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithms
The project uses four machine learning algorithms for training and evaluation:
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Support Vector Machine (SVM)

## Project Workflow
1. Import required libraries and load the dataset.
2. Perform statistical analysis.
3. Handle missing values and duplicates.
4. Detect and cap outliers.
5. Encode categorical features.
6. Separate independent and dependent variables.
7. Visualize the dataset.
8. Split the dataset into training and testing sets.
9. Apply feature selection and standardization.
10. Train and evaluate four machine learning algorithms.

## Dataset
The dataset contains credit card transaction details used to train and test machine learning models.

## Evaluation Metrics
The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Conclusion
This project demonstrates how machine learning techniques can be used to detect fraudulent credit card transactions. By comparing different algorithms, the project helps identify a suitable model for fraud detection.
